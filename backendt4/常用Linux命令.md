# 常用 Linux 命令（详细用法）

---

## 一、文件与目录操作

### ls —— 列出目录内容
- **作用**：列出当前目录或指定路径下的文件和文件夹
- **语法**：`ls [选项] [路径]`
- **常用选项**：
  - `-l`：以长格式详细显示（权限、链接数、所有者、所属组、大小、修改时间）
  - `-a`：显示所有文件，包括以 `.` 开头的隐藏文件
  - `-h`：文件大小以易读单位（K、M、G）显示，常与 `-l` 连用
  - `-t`：按修改时间从新到旧排序
  - `-r`：反向排序
  - `-S`：按文件大小从大到小排序
  - `-R`：递归显示子目录内容
- **示例**：
  - `ls -lh`：以易读大小显示当前目录的详细列表
  - `ls -lat`：按时间倒序显示所有文件（含隐藏文件）
  - `ls /etc/nginx`：查看指定目录内容

### cd —— 切换目录
- **作用**：切换当前工作目录
- **语法**：`cd [路径]`
- **说明**：不接参数时回到当前用户主目录（`~`）；`cd ..` 返回上级目录；`cd -` 返回上一次所在目录；`cd ~` 回到主目录
- **示例**：
  - `cd /var/log`：进入 /var/log 目录
  - `cd ..`：回到上一级目录
  - `cd ~/projects`：进入用户主目录下的 projects 目录

### pwd —— 显示当前工作目录
- **作用**：显示当前所在目录的绝对路径
- **语法**：`pwd [选项]`
- **说明**：`pwd -P` 显示真实物理路径（不显示符号链接）
- **示例**：`pwd`

### mkdir —— 创建目录
- **作用**：创建新目录
- **语法**：`mkdir [选项] 目录名`
- **常用选项**：
  - `-p`：递归创建多级目录，父目录不存在时自动创建
  - `-v`：显示创建过程
  - `-m 权限`：创建时直接指定权限，如 `mkdir -m 755 newdir`
- **示例**：
  - `mkdir test`：创建 test 目录
  - `mkdir -p a/b/c`：一次性创建多级目录 a/b/c
  - `mkdir -p project/{src,bin,docs}`：同时创建多个子目录

### rmdir —— 删除空目录
- **作用**：删除空目录（目录非空会报错）
- **语法**：`rmdir [选项] 目录名`
- **说明**：`rmdir -p a/b/c` 删除 c 后，若 b、a 也为空则一并删除
- **示例**：`rmdir empty_dir`

### rm —— 删除文件或目录
- **作用**：删除文件或目录
- **语法**：`rm [选项] 文件或目录`
- **常用选项**：
  - `-r`：递归删除目录及其全部内容
  - `-f`：强制删除，不询问确认
  - `-i`：删除前逐一询问确认
  - `-v`：显示删除过程
- **示例**：
  - `rm file.txt`：删除单个文件
  - `rm -rf temp/`：强制递归删除 temp 目录（⚠️ 谨慎使用，不可恢复）
  - `rm -i *.log`：逐一确认删除所有 .log 文件

### cp —— 复制文件或目录
- **作用**：复制文件或目录
- **语法**：`cp [选项] 源 目标`
- **常用选项**：
  - `-r`：递归复制目录
  - `-i`：目标存在时询问是否覆盖
  - `-p`：保留原文件的权限、时间戳等属性
  - `-a`：完整保留所有属性（常用于备份）
  - `-v`：显示复制过程
- **示例**：
  - `cp a.txt b.txt`：复制并重命名
  - `cp -r src/ dest/`：递归复制整个目录
  - `cp -a /home/user/data /backup/`：完整保留属性复制

### mv —— 移动或重命名
- **作用**：移动文件/目录，也可用于重命名
- **语法**：`mv [选项] 源 目标`
- **常用选项**：
  - `-i`：目标存在时询问是否覆盖
  - `-f`：强制覆盖，不询问
  - `-v`：显示移动过程
- **示例**：
  - `mv a.txt b.txt`：重命名
  - `mv a.txt /tmp/`：移动文件到 /tmp 目录

### touch —— 创建空文件或更新时间戳
- **作用**：文件不存在则创建空文件；已存在则更新其访问/修改时间为当前时间
- **语法**：`touch [选项] 文件名`
- **常用选项**：`-t 时间`：把文件时间戳改为指定时间，如 `touch -t 202601011200 file.txt`
- **示例**：`touch newfile.txt`

### find —— 查找文件
- **作用**：在指定路径下按条件查找文件
- **语法**：`find 路径 [条件] [动作]`
- **常用条件**：
  - `-name "模式"`：按文件名匹配（支持通配符 `*`、`?`）
  - `-type f / d`：按类型筛选（f=普通文件，d=目录）
  - `-size +10M`：查找大于 10MB 的文件
  - `-mtime -7`：查找最近 7 天内修改过的文件
  - `-user 用户名`：按文件所有者查找
  - `-exec 命令 {} \;`：对查找结果执行命令
- **示例**：
  - `find /home -name "*.log"`：查找 /home 下所有 .log 文件
  - `find /var -type f -size +100M`：查找 /var 下大于 100MB 的文件
  - `find . -name "*.tmp" -exec rm {} \;`：找到并删除所有 .tmp 文件

### tree —— 树状显示目录结构
- **作用**：以树状层级显示目录结构
- **语法**：`tree [选项] [目录]`
- **常用选项**：`-L 2`（限制显示层级深度）、`-d`（只显示目录）、`-a`（含隐藏文件）
- **示例**：`tree -L 2 /etc`

### file —— 查看文件类型
- **作用**：识别文件的真实类型
- **语法**：`file 文件名`
- **示例**：`file a.txt` 输出 `ASCII text`；`file logo.png` 输出 `PNG image data...`

## 二、文件内容查看与编辑

### cat —— 连接并显示文件内容
- **作用**：查看文件全部内容，或合并多个文件
- **语法**：`cat [选项] 文件`
- **常用选项**：`-n`（显示行号）、`-b`（仅对非空行编号）、`-A`（显示不可见字符）
- **示例**：
  - `cat /etc/hostname`：显示文件内容
  - `cat a.txt b.txt > c.txt`：合并两个文件到 c.txt
  - `cat -n file.txt`：带行号显示

### less —— 分页查看
- **作用**：分页查看大文件内容，支持向前/向后翻页和搜索
- **语法**：`less 文件`
- **操作说明**：`空格`/`PgDn` 下翻页；`b`/`PgUp` 上翻；`g` 跳到开头；`G` 跳到末尾；`/关键词` 向下搜索；`?关键词` 向上搜索；`q` 退出
- **示例**：`less /var/log/syslog`

### more —— 分页查看（简单版）
- **作用**：分页查看文件内容（功能较 less 简单）
- **语法**：`more 文件`
- **操作说明**：`空格` 下翻页；`Enter` 下翻一行；`q` 退出；不支持向上翻页

### head —— 查看文件开头
- **作用**：查看文件开头部分
- **语法**：`head [选项] 文件`
- **常用选项**：`-n 行数`（指定显示行数，默认 10）、`-c 字节数`（按字节截取）
- **示例**：
  - `head -n 5 file.txt`：查看前 5 行
  - `head -20 file.txt`：查看前 20 行（-n 可省略）

### tail —— 查看文件末尾
- **作用**：查看文件末尾部分
- **语法**：`tail [选项] 文件`
- **常用选项**：`-n 行数`（指定行数）、`-f`（实时跟踪文件新增内容，`Ctrl+C` 退出）
- **示例**：
  - `tail -n 50 file.txt`：查看末尾 50 行
  - `tail -f /var/log/syslog`：实时监控日志输出（运维常用）

### grep —— 文本搜索
- **作用**：在文件或命令输出中搜索包含指定模式的行
- **语法**：`grep [选项] 模式 文件`
- **常用选项**：
  - `-r`：递归搜索整个目录
  - `-i`：忽略大小写
  - `-n`：显示匹配行行号
  - `-v`：反向匹配（排除含模式的行）
  - `-c`：只统计匹配行数
  - `-E`：使用扩展正则表达式
- **示例**：
  - `grep -rn "error" /var/log/`：递归搜索 error 关键词
  - `grep -i "root" /etc/passwd`
  - `ps aux | grep nginx`：配合管道过滤进程信息

### wc —— 统计行数/单词数/字节数
- **作用**：统计文件的行数、单词数、字节数
- **语法**：`wc [选项] 文件`
- **常用选项**：`-l`（行数）、`-w`（单词数）、`-c`（字节数）、`-m`（字符数）
- **示例**：`wc -l file.txt`：统计文件行数

### sort —— 排序
- **作用**：对文件内容排序输出
- **语法**：`sort [选项] 文件`
- **常用选项**：`-n`（按数值大小排序）、`-r`（倒序）、`-k 列号`（按指定列排序）、`-u`（去重）
- **示例**：
  - `sort -n scores.txt`：按数值排序
  - `sort -k2 file.txt`：按第 2 列排序

### uniq —— 去除相邻重复行
- **作用**：去除相邻的重复行（常与 sort 配合使用）
- **语法**：`uniq [选项] [输入文件] [输出文件]`
- **常用选项**：`-c`（统计每行出现次数）、`-d`（只显示重复行）、`-u`（只显示唯一行）
- **示例**：`sort file.txt | uniq -c`：统计各元素出现次数

### cut —— 按列提取文本
- **作用**：按分隔符或字符位置提取指定列
- **语法**：`cut -d 分隔符 -f 列号 文件`
- **常用选项**：`-d`（指定分隔符）、`-f`（取第几列，支持 `1,3` 或 `1-3`）、`-c`（按字符位置截取）
- **示例**：`cut -d: -f1 /etc/passwd`：提取所有用户名列表

### diff —— 比较文件差异
- **作用**：逐行比较两个文件的差异
- **语法**：`diff [选项] 文件1 文件2`
- **常用选项**：`-u`（统一格式输出，更易读）、`-r`（递归比较目录）、`-q`（只报告是否有差异）
- **示例**：`diff -u old.txt new.txt`

### vim / vi —— 文本编辑器
- **作用**：打开文件进行编辑（终端下最常用的编辑器）
- **语法**：`vim 文件`
- **操作说明**：三种模式——
  - 普通模式（默认）：按 `i` 进入插入模式，按 `:` 进入命令行模式
  - 插入模式：编辑文本，按 `Esc` 返回普通模式
  - 命令行模式：`:w` 保存、`:q` 退出、`:wq` 保存并退出、`:q!` 不保存强制退出
- **示例**：`vim /etc/nginx/nginx.conf`

### nano —— 简单文本编辑器
- **作用**：界面更友好的简易编辑器
- **语法**：`nano 文件`
- **操作说明**：底部有快捷键提示；`Ctrl+O` 保存、`Ctrl+X` 退出、`Ctrl+W` 搜索
- **示例**：`nano notes.txt`

## 三、权限与用户管理

### chmod —— 修改文件权限
- **作用**：修改文件或目录的读、写、执行权限
- **语法**：`chmod [选项] 权限 文件`
- **权限表示**：
  - 数字法：r=4、w=2、x=1，相加得到权限值。如 `755` = 所有者 `rwx`(7)、组 `r-x`(5)、其他人 `r-x`(5)
  - 符号法：`u`(所有者) / `g`(组) / `o`(其他人) / `a`(所有人) + `+`/`-` + `r`/`w`/`x`
- **常用选项**：`-R` 递归修改目录下所有文件
- **示例**：
  - `chmod 755 script.sh`：所有者可读写执行，组和其他可读执行
  - `chmod -R 644 docs/`：递归设置 docs 下文件为 644
  - `chmod u+x run.sh`：为所有者添加执行权限
  - `chmod a+x app.py`：所有人可执行

### chown —— 修改文件所有者
- **作用**：修改文件或目录的所有者和所属组
- **语法**：`chown [选项] 用户[:组] 文件`
- **常用选项**：`-R` 递归修改
- **示例**：
  - `chown root file.txt`：修改所有者
  - `chown user:group file.txt`：同时修改所有者和所属组
  - `chown -R www-data:www-data /var/www`：递归修改 Web 目录归属（部署常用）

### whoami —— 显示当前用户名
- **作用**：显示当前登录用户
- **语法**：`whoami`
- **示例**：`whoami`

### id —— 显示用户身份信息
- **作用**：显示当前用户（或指定用户）的 UID、GID 和所属组
- **语法**：`id [用户名]`
- **示例**：`id`（当前用户）；`id root`（查看 root 信息）

### sudo —— 以管理员权限执行
- **作用**：以 root（管理员）权限执行命令
- **语法**：`sudo 命令`
- **说明**：首次使用需输入当前用户密码；`sudo -i` 进入 root shell；`sudo -u 用户名 命令` 以指定用户身份执行
- **示例**：`sudo apt install nginx`

### su —— 切换用户
- **作用**：切换到其他用户身份
- **语法**：`su - 用户名`
- **说明**：`-` 表示同时切换到该用户的完整环境；不带用户名默认切换到 root；用 `exit` 退回原用户
- **示例**：`su - alice`

### useradd —— 创建用户
- **作用**：创建新系统用户
- **语法**：`useradd [选项] 用户名`
- **常用选项**：`-m`（自动创建主目录）、`-s /bin/bash`（指定登录 shell）、`-G 组名`（加入附加组）、`-d 路径`（指定主目录）
- **示例**：`sudo useradd -m -s /bin/bash alice`

### passwd —— 设置/修改密码
- **作用**：设置或修改用户登录密码
- **语法**：`passwd [用户名]`
- **说明**：root 可修改任意用户密码；普通用户只能修改自己的；`passwd -l 用户名` 锁定账号
- **示例**：`sudo passwd alice`

### groupadd —— 创建用户组
- **作用**：创建新的用户组
- **语法**：`groupadd [选项] 组名`
- **示例**：`sudo groupadd developers`

## 四、进程管理

### ps —— 查看进程
- **作用**：查看当前系统中的进程信息（静态快照）
- **语法**：`ps [选项]`
- **常用选项**：`aux`（显示所有用户进程的详细信息）、`-ef`（全格式显示）、`-ef | grep 关键词`（过滤指定进程）
- **示例**：`ps aux | grep nginx`

### top —— 动态查看进程与资源
- **作用**：实时动态显示进程及 CPU/内存占用
- **语法**：`top`
- **操作说明**：`q` 退出；`M` 按内存排序；`P` 按 CPU 排序；`k` 输入 PID 杀进程；`1` 查看每个 CPU 核心
- **示例**：`top`

### htop —— 增强版进程查看器
- **作用**：top 的增强版，界面更友好
- **语法**：`htop`
- **说明**：需先安装（`sudo apt install htop`）；支持鼠标操作、F9 杀进程、F6 选择排序方式

### kill —— 结束进程
- **作用**：向指定进程发送信号（默认结束进程）
- **语法**：`kill [信号] 进程号(PID)`
- **常用信号**：`-9`（SIGKILL，强制结束，无法被忽略）、`-15`（SIGTERM，正常终止，默认）
- **示例**：
  - `kill 1234`：正常结束 PID 为 1234 的进程
  - `kill -9 1234`：强制结束（进程卡死时使用）
  - `ps aux | grep python` 找到 PID 后执行 `kill 对应PID`

### pkill —— 按名称结束进程
- **作用**：按进程名匹配并结束进程（无需先查 PID）
- **语法**：`pkill [选项] 进程名`
- **示例**：`pkill -9 nginx`：强制结束所有 nginx 进程

### jobs / bg / fg —— 后台任务管理
- **jobs**：查看当前终端会话的后台任务列表（显示任务编号 `[1]`）
- **bg**：将暂停的任务放到后台继续运行
- **fg**：将后台任务调到前台运行
- **语法**：`bg %任务编号`、`fg %任务编号`
- **示例**：
  - `sleep 100 &`：把 sleep 放到后台
  - `jobs`：查看任务列表
  - `fg %1`：把 1 号任务调回前台

### nohup —— 后台持续运行
- **作用**：让命令在后台持续运行，终端关闭后进程不退出
- **语法**：`nohup 命令 &`
- **说明**：标准输出默认写入 `nohup.out` 文件；`2>&1` 把错误输出也重定向到日志
- **示例**：`nohup python app.py > app.log 2>&1 &`：后台运行 Python 程序并记录日志

### & —— 后台执行符号
- **作用**：放在命令末尾，把命令放到后台执行，立即返回 shell 提示符
- **语法**：`命令 &`
- **示例**：`ping -c 100 example.com > ping.log &`

## 五、系统信息与资源监控

### uname —— 查看系统信息
- **作用**：查看系统内核及版本信息
- **语法**：`uname [选项]`
- **常用选项**：`-a`（显示全部信息）、`-r`（内核版本）、`-m`（硬件架构）、`-n`（主机名）
- **示例**：`uname -a`

### hostname —— 主机名
- **作用**：查看或临时修改主机名
- **语法**：`hostname`（查看）；`sudo hostname 新名称`（临时修改，重启失效）
- **示例**：`hostname`

### date —— 日期时间
- **作用**：查看或设置系统日期时间
- **语法**：`date [格式]`
- **常用格式**：`+%Y-%m-%d`（年月日）、`+%H:%M:%S`（时分秒）、`+%F %T`（标准日期+时间）
- **示例**：
  - `date`：输出默认格式
  - `date "+%Y-%m-%d %H:%M:%S"`：自定义格式输出

### uptime —— 运行时长与负载
- **作用**：查看系统运行时长、登录用户数和系统负载
- **语法**：`uptime`
- **说明**：最后三个数字分别表示 1 分钟、5 分钟、15 分钟的平均负载
- **示例**：`uptime`

### free —— 内存使用情况
- **作用**：查看物理内存和交换分区（swap）使用情况
- **语法**：`free [选项]`
- **常用选项**：`-h`（易读单位显示）、`-m`（以 MB 为单位）、`-s 秒`（每隔 N 秒刷新）
- **示例**：`free -h`

### df —— 磁盘空间
- **作用**：查看各磁盘分区及挂载点的空间使用情况
- **语法**：`df [选项] [挂载点]`
- **常用选项**：`-h`（易读单位）、`-T`（显示文件系统类型）
- **示例**：`df -h`

### du —— 目录占用空间
- **作用**：统计文件或目录占用的磁盘空间
- **语法**：`du [选项] 路径`
- **常用选项**：`-s`（只显示总计）、`-h`（易读单位）、`-a`（显示每个文件）、`--max-depth=N`（限制目录深度）
- **示例**：
  - `du -sh /var`：查看 /var 目录总大小
  - `du -h --max-depth=1 /home`：查看 /home 下各一级子目录大小

### dmesg —— 内核日志
- **作用**：查看内核启动及运行日志（硬件、驱动相关信息）
- **语法**：`dmesg [选项]`
- **说明**：需 root 权限查看完整输出；常配合 `| tail` 查看最近的日志
- **示例**：`dmesg | tail -20`

### lscpu —— CPU 详细信息
- **作用**：查看 CPU 架构、核心数、线程数、频率、缓存等
- **语法**：`lscpu`
- **示例**：`lscpu`

### lsblk —— 块设备信息
- **作用**：以树状显示磁盘、分区等块设备信息
- **语法**：`lsblk [选项]`
- **常用选项**：`-f`（同时显示文件系统类型和 UUID）
- **示例**：`lsblk -f`

### ip —— 网络配置管理
- **作用**：查看和管理网络接口、IP 地址、路由（新系统推荐使用）
- **语法**：`ip addr`（查看 IP 地址）、`ip route`（查看路由表）、`ip link`（查看网卡状态）
- **示例**：`ip addr`

### ping —— 网络连通性测试
- **作用**：测试与目标主机的网络连通性及延迟
- **语法**：`ping [选项] 主机`
- **常用选项**：`-c 次数`（指定发送次数后停止）、`-i 秒`（发送间隔）、`-4`/`-6`（IPv4/IPv6）
- **示例**：`ping -c 4 baidu.com`

### netstat —— 网络连接与端口
- **作用**：查看网络连接、路由表、端口监听状态
- **语法**：`netstat [选项]`
- **常用选项**：`-t`（TCP）、`-u`（UDP）、`-l`（仅监听）、`-n`（数字显示地址和端口）、`-p`（显示进程）
- **示例**：`netstat -tulnp`：查看所有监听端口及对应进程

### ss —— 网络连接（netstat 替代）
- **作用**：查看网络连接和端口信息（更快，现代替代工具）
- **语法**：`ss [选项]`
- **常用选项**：`-tulnp`（查看监听端口及进程）、`-s`（汇总统计）、`-a`（显示所有连接）
- **示例**：`ss -tulnp`

## 六、软件包管理（Ubuntu/Debian 系）

### apt —— 软件包管理器
- **作用**：安装、卸载、升级、搜索软件包
- **语法**：`sudo apt [子命令] [选项] 软件包`
- **常用子命令**：
  - `update`：更新软件源索引列表
  - `upgrade`：升级所有可升级的软件包
  - `install 包名`：安装指定软件包
  - `remove 包名`：卸载软件包（保留配置文件）
  - `purge 包名`：彻底卸载（连同配置文件一起删除）
  - `search 关键词`：搜索软件包
  - `list --installed`：列出所有已安装软件包
  - `show 包名`：查看软件包详细信息
- **说明**：安装/卸载/升级需要 sudo 权限；新装系统后建议先执行 `apt update`
- **示例**：
  - `sudo apt update && sudo apt upgrade`：更新索引并升级系统
  - `sudo apt install nginx`：安装 nginx
  - `sudo apt remove nginx`：卸载 nginx

### dpkg —— 底层软件包管理
- **作用**：Debian 底层包管理工具（apt 的底层实现）
- **语法**：`dpkg [选项] 包名`
- **常用选项**：`-l`（列出所有已安装包）、`-i 文件.deb`（安装本地 .deb 包）、`-r 包名`（卸载）、`-L 包名`（查看包安装的文件）
- **示例**：`dpkg -l | grep nginx`：检查 nginx 是否已安装

## 七、压缩与解压

### tar —— 打包/解包（Linux 最常用）
- **作用**：打包多个文件/目录，并可配合 gzip/bzip2 压缩
- **语法**：`tar [选项] 归档文件名 [文件/目录]`
- **常用选项组合**：
  - `-czvf 目标.tar.gz 目录`：打包并用 gzip 压缩（c=创建、z=gzip、v=显示过程、f=指定文件名）
  - `-xzvf 包.tar.gz`：解压 gzip 格式包（x=解压）
  - `-cjvf 目标.tar.bz2 目录`：打包并用 bzip2 压缩
  - `-xjvf 包.tar.bz2`：解压 bzip2 格式包
  - `-tf 包.tar.gz`：不解压，仅查看包内文件列表
- **说明**：`-C 目录` 指定解压到目标目录
- **示例**：
  - `tar -czvf backup.tar.gz /home/user/data`：压缩备份
  - `tar -xzvf backup.tar.gz -C /restore/`：解压到指定目录
  - `tar -tf backup.tar.gz`：查看压缩包内容

### zip / unzip —— zip 格式压缩与解压
- **作用**：创建和解压 zip 格式压缩包（Windows/Linux 通用格式）
- **语法**：`zip -r 目标.zip 目录`；`unzip 文件.zip [-d 目录]`
- **常用选项**：zip：`-r`（递归压缩目录）、`-q`（安静模式）；unzip：`-d 目录`（解压到指定目录）、`-l`（列出内容）
- **示例**：
  - `zip -r archive.zip ./docs`：压缩 docs 目录
  - `unzip archive.zip -d /tmp/`：解压到 /tmp 目录
  - `unzip -l archive.zip`：查看压缩包内容

## 八、网络与远程连接

### curl —— 网络请求工具
- **作用**：发起 HTTP/HTTPS 等网络请求，常用于接口测试和文件下载
- **语法**：`curl [选项] URL`
- **常用选项**：
  - `-X 方法`：指定请求方法（GET/POST/PUT/DELETE）
  - `-H "头信息"`：添加请求头，如 `-H "Content-Type: application/json"`
  - `-d "数据"`：POST 提交数据
  - `-o 文件名`：将响应保存到文件
  - `-I`：只查看响应头
  - `-s`：静默模式（不显示进度信息）
- **示例**：
  - `curl http://example.com`：GET 请求
  - `curl -X POST -H "Content-Type: application/json" -d '{"name":"tom"}' http://api.example.com/users`
  - `curl -o page.html http://example.com`：下载页面到文件

### wget —— 文件下载工具
- **作用**：从网络下载文件，支持断点续传和递归下载
- **语法**：`wget [选项] URL`
- **常用选项**：`-O 文件名`（保存为指定文件名）、`-c`（断点续传）、`-r`（递归下载）、`-q`（安静模式）
- **示例**：`wget -c https://example.com/file.zip`：下载并支持断点续传

### ssh —— 远程登录
- **作用**：安全加密地远程登录到另一台主机
- **语法**：`ssh [选项] 用户@主机`
- **常用选项**：`-p 端口`（指定连接端口，默认 22）、`-i 密钥文件`（使用指定私钥认证）
- **示例**：
  - `ssh root@192.168.1.100`：默认端口登录
  - `ssh -p 2222 user@192.168.1.100`：指定端口登录
  - `ssh -i ~/.ssh/id_rsa user@server`：密钥登录

### scp —— 远程复制文件
- **作用**：在本地与远程主机之间安全复制文件（基于 SSH）
- **语法**：
  - 本地上传：`scp 本地文件 用户@主机:远程路径`
  - 远程下载：`scp 用户@主机:远程路径 本地路径`
  - `-r`：递归复制目录；`-P 端口`：指定端口
- **示例**：
  - `scp file.txt user@192.168.1.100:/home/user/`：上传
  - `scp -r user@192.168.1.100:/var/log/ ./logs/`：递归下载目录
  - `scp -P 2222 file.txt user@server:/tmp/`：指定端口上传

### ifconfig —— 网络接口信息（旧工具）
- **作用**：查看和配置网络接口信息（旧版工具）
- **语法**：`ifconfig`；`ifconfig 网卡名`
- **说明**：新版 Ubuntu 需先安装 `sudo apt install net-tools`；新系统推荐使用 `ip addr`
- **示例**：`ifconfig eth0`

## 九、其他常用命令

### echo —— 输出文本
- **作用**：输出文本内容到屏幕，常用于打印变量或生成文件内容
- **语法**：`echo [选项] 内容`
- **常用选项**：`-n`（输出后不换行）、`-e`（启用转义字符，如 `\n` 换行）
- **示例**：
  - `echo "Hello World"`
  - `echo -e "第一行\n第二行"`
  - `echo $PATH`：输出环境变量 PATH 的值

### clear —— 清空屏幕
- **作用**：清空终端屏幕内容
- **语法**：`clear`
- **说明**：快捷键 `Ctrl+L` 效果相同

### history —— 命令历史
- **作用**：查看当前用户执行过的命令历史
- **语法**：`history [数量]`
- **说明**：`!编号` 重新执行指定编号的历史命令；`Ctrl+R` 反向搜索历史命令
- **示例**：`history 20`：显示最近 20 条命令

### man —— 查看手册
- **作用**：查看命令的完整帮助手册
- **语法**：`man 命令`
- **操作说明**：进入后 `/关键词` 搜索、`q` 退出；手册按章节分类（1=普通命令、5=配置文件、8=系统管理）
- **示例**：`man ls`

### --help —— 简要帮助
- **作用**：查看命令的简要帮助信息（比 man 更简洁）
- **语法**：`命令 --help` 或 `命令 -h`
- **示例**：`tar --help`

### alias —— 命令别名
- **作用**：为常用命令设置简短的别名
- **语法**：`alias 别名='命令'`
- **说明**：仅对当前会话有效；永久生效需写入 `~/.bashrc`；`unalias 别名` 取消别名
- **示例**：
  - `alias ll='ls -lh'`：以后输入 ll 即可显示详细列表
  - `alias gs='git status'`

### export —— 设置环境变量
- **作用**：设置环境变量，对当前 shell 及其子进程生效
- **语法**：`export 变量名=值`
- **说明**：临时生效；永久生效需写入 `~/.bashrc`（用户级）或 `/etc/profile`（系统级），然后 `source ~/.bashrc` 使生效
- **示例**：`export JAVA_HOME=/usr/lib/jvm/java-11`

### which —— 定位命令路径
- **作用**：查看某个命令所在的可执行文件路径
- **语法**：`which 命令`
- **示例**：`which python3` 输出类似 `/usr/bin/python3`

### ln —— 创建链接
- **作用**：创建文件链接（软链接类似 Windows 快捷方式）
- **语法**：`ln -s 源文件 链接名`
- **说明**：`-s` 创建软链接（符号链接）；不加 `-s` 创建硬链接
- **示例**：`ln -s /opt/app/bin/app /usr/local/bin/app`：为应用创建全局命令入口

### shutdown —— 关机/重启
- **作用**：按计划关机或重启系统
- **语法**：`sudo shutdown [选项] [时间]`
- **常用选项**：`-h`（关机）、`-r`（重启）、`now`（立即执行）、`+10`（10 分钟后执行）
- **示例**：
  - `sudo shutdown -h now`：立即关机
  - `sudo shutdown -r +5`：5 分钟后重启

### reboot —— 重启系统
- **作用**：立即重启系统
- **语法**：`sudo reboot`
- **说明**：需要 root 权限

---

> **提示**：所有命令均可用 `man 命令` 或 `命令 --help` 查看更完整的参数说明。涉及系统修改、删除、安装类操作时建议先确认命令含义再执行。
