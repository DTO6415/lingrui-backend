# 理论部分

1. 什么是数据库？
    数据(Data)是未经整理、修饰的文本、信息，数据库(Database)则是一个**存放和管理数据的系统**，它使用户能够高效地新建、删除、搜索、替换数据。

2. 数据库能解决什么问题？
    要解答这个问题，需要把数据库和文件(另一种存储数据的结构)做对比。
    1. 数据的**高效检索**和**整理**。哪怕数据库中有上亿条数据，也能通过特定的算法高效检索到需要的数据。
    2. 多人**协作**维护数据。数据库可以使多个用户同时对数据进行操作，而不产生冲突或覆盖的问题。
    3. **精确**的权限管理。数据库能将权限设置精确到字段，对用户的权限设置更为精细。
    4. 有利于**复杂**的数据综合处理和决策。SQL语言赋予了数据库更高的操作上限。
    相比于文件，在上述情况下数据库都有更出色的表现。

3. SQL与数据库的关系？
    SQL是一种**查询语言**，用于用户与数据库**交互**。换句话说，用户想要操作数据库(新建、删除、搜索、替换)，就必须使用SQL进行操作。
    
    我认为SQL是一种介于命令和编程语言之间的语言：它看上去、用上去就像是命令行中的命令，但它的语法逻辑更像编程语言。

4. SQL基本语法的学习理解

   - `CREATE TABLE` 用于创建新表。

    ```SQL
        CREATE TABLE 表名 (
            列名 数据类型,
            列名 数据类型,
            列名 数据类型
        );
    ```

    - `INSERT` 用于插入数据。

    ```SQL
    INSERT INTO 表名(列名，列名...)
        VALUE (数据)
    ```

    - `SELECT` 用于查找数据。
    值得注意的是，`SELECT`并不是专用于查找数据用的，而是更像返回我询问的数据，如

    ```SQL
    SELECT name FROM members;
    ```

    就是返回我询问的'name'；而

    ```SQL
    SELECT 1 + 2;
    ```

    就会返回我询问的`1+2`是多少。

    - `UPDATE`用于更新信息，即替换。

    ```SQL
    UPDATE 表名
    SET 用于替换的数据
    WHERE 替换的条件(位置)
    ```

    `WHERE` 用于限定范围(查找、替换)。
